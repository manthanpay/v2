# Manthan Pay — Theme B: Village Market

This project is an alternative visual direction for the same Manthan Pay application.

## What is intentionally unchanged

- Business logic
- Authentication and local session behavior
- Signup/login validation
- MPIN validation
- Wallet calculations
- Transaction flow and receipt flow
- Service data and commissions
- 11-language i18n architecture
- Logo assets
- Existing service images and map
- Existing AEPS tutorial video
- Form component and validation rules

## What is different

- New visual identity: village-market / community-network
- Warm cream, forest green, terracotta and mustard palette
- Rounded editorial navigation
- Different hero composition
- Large village banner chapter using the existing Indian village banner assets
- Different service-card layout
- More editorial section spacing
- Framed map/presence section
- Reworked partner and dashboard surfaces
- Different mobile breakpoints and card behavior

## Reference / comparison

### Original
- Blue / orange fintech-corporate presentation
- Conventional fintech card grid
- Original hero and section rhythm

### Theme B
- Indian rural-commerce visual language
- Warm paper/cream surfaces
- Forest-green trust color
- Terracotta action color
- Larger photographic chapters
- More editorial, magazine-like section rhythm

Use this project side-by-side with the current deployed project when showing the team two design directions.

## Run locally

```bash
npm install
npm run dev
```

Then open the Vite localhost URL, normally:

`http://localhost:5173/manthan-pay/`

## Build

```bash
npm run build
```

The Vite base path remains `/manthan-pay/`, matching the existing project configuration.
